訪問鍼灸・あん摩マッサージ指圧料金シミュレーター
Home Visit Amma-Massage-Shiatsu, Acupuncture & Moxibustion Calculator
(h-v-ams_ac_mx_calc)

1. プロジェクト概要

訪問鍼灸マッサージ料金シミュレーター（Home Visit Amma-Massage-Shiatsu, Acupu
ncture & Moxibustion Calculator、略称 h-v-ams_ac_mx_calc）は、受領委任制度下
の療養費に基づく訪問あん摩マッサージ指圧・はり・きゅうの施術料をブラウザ上で
試算するJavaScriptプログラムです。

計算ロジックとユーザーインターフェースを分離した構成を採用しており、施術内容
や負担割合の変更に応じて施術料および料金表を動的に再計算・再表示できます。

HTMLから本JavaScriptを読み込むだけで利用でき、外部ライブラリやサーバーサイド
環境は必要ありません。動作確認用のサンプルHTMLも添付しているため、そのまま料
金シミュレーターとして利用することも、既存のWebページへ組み込むことも可能で
す。

2. システム要件

必要な環境
本プロジェクトはHTMLおよびJavaScriptに対応したWebブラウザで動作します。
（ECMAScript 2015（ES6）以降対応）

Webサーバー上に配置したHTMLから読み込んで利用します。外部ライブラリは必要あ
りません。サンプルHTMLも添付しているため、動作確認後、そのまま料金シミュレー
ターとして利用できます。

3. 特徴

・ブラウザ上で動作
・HTMLから読み込むだけで利用可能
・外部ライブラリ不要
・訪問あん摩マッサージ指圧、はり、きゅうの施術料計算に対応
・負担割合に応じた自己負担額を自動計算
・料金一覧表を動的に生成・更新

4. 対応している制度
対象
受領委任制度によるあん摩マッサージ指圧師、はり師、きゅう師の訪問施術の療養費

さらに、健康保険（公的医療保険）上の負担割合
・1割
・2割
・3割
・全額負担（10割）

7. 計算内容

利用者様の負担額を表示するために以下の計算を行っている

( 施術料 + 訪問施術料 ) / 負担割合計算 = 一部負担金

・マッサージ
・変形徒手矯正
・鍼
・きゅう

・変形徒手矯正
・温罨法
・電気温罨法
・鍼
・きゅう
・電療料
